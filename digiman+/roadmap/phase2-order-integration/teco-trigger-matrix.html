Legend
  • MONoKnown = apakah SAP MO Number sudah confirmed di titik itu. Reuse-MOOpenOnly dan EscapeHatch selalu Ya (struktural — MOOpen sumbernya data SAP yang sudah confirmed; escape hatch diisi manual). OrderBaru selalu Tidak (order-nya belum di-create).

  • OrderBaru + ButuhMaterial=Tidak = disebut B1; ButuhMaterial=Ya = disebut B2, di bagian lain dokumen.
  • ⚠ (baris 19) = Accepted Risk — declare NoPartsRequired tidak diverifikasi ke SAP.
  • BacklogExecutionList.MONumber NOT NULL → TECO tidak pernah terjadi sebelum MONoKnown=Ya. Baris 3 & 13 ("begitu MONo confirmed") menunggu event konfirmasi SAP dulu, baru trigger.
